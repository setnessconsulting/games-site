# Games site architecture

`games-site` is the public arcade shell. Each game keeps its source in a separate repository and
publishes a versioned browser build to the shared private R2 bucket.

## Request flow

1. A visitor opens `https://games.setnessconsulting.com/` and sees the catalog generated by Astro.
2. The Signal Garden launcher lives at `/signal-garden/`.
3. The play view lives at `/signal-garden/play/`.
4. Unity build files are requested from `/game-assets/<slug>/<version>/<path>`.
5. The Pages Function validates the release and streams the matching object from R2.

Pages hosts the small HTML, CSS, JavaScript, and artwork shell. R2 holds large game artifacts so
the site is not constrained by Pages' per-file asset limit.
